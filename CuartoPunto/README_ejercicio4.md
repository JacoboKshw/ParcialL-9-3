# Comparacion de rendimiento: C vs Python

Compara un lenguaje compilado (C) y uno interpretado (Python) usando Fibonacci recursivo.

## Archivos
- `fibonacci.c` — version en C
- `fibonacci.py` — version en Python

## Compilar y ejecutar
```
cc fibonacci.c 
./a.out
python3 fibonacci.py
```
